================================================================================
USAGE: COMPONENT PLACEMENT ALGORITHM
================================================================================

For each unplaced block at grid position [Row, Col] in each matrix:

1. Determine target anchor point:
   target_x = matrix_anchor_x + (Col - 1) × 508.70 mil
   target_y = matrix_anchor_y + (Row - 1) × 520.00 mil

2. For each component in the corresponding matrix template:
   component_x = target_x + rel_x_mil
   component_y = target_y + rel_y_mil

3. Apply this to all components in the template for that matrix

Example (matrix3, Row 2, Col 2):
   target_x = 991.00 + (2-1) × 508.70 = 1499.70 mil
   target_y = 5547.00 + (2-1) × 520.00 = 6067.00 mil
   
   R1 position: x = 1499.70 + 60.00 = 1559.70 mil
                y = 6067.00 + 0.00 = 6067.00 mil

KEY OBSERVATIONS
================================================================================

1. All three matrices use the same component template pattern with identical 
   relative positions within each [1,1] block cell.

2. Designators follow pattern: Component_RefDes$CBBxx/CBByy
   - Component_RefDes: R1, R2, C1, C2, C3, C4, Q5, Q6, Q8, Q9
   - CBBxx: Schematic block reference for matrix3 row 1
   - CBByy: Extended reference indicator

3. Component variations by matrix:
   - matrix3 [1,1]: 10 components (all R, C, Q types)
   - matrix8 [1,1]: 9 components (missing one pair, possibly)
   - matrix33 [1,1]: 9 components (uses MUL_NO_H_CELL variant)

4. X spacing between components varies by matrix (affects block width):
   - matrix3: 200 mil wide (890-1090)
   - matrix8: 195 mil wide (890-1085) - slightly narrower
   - matrix33: 125 mil wide (1185-1310) - much narrower (higher density)

5. Y spacing is consistent across all matrices: 190 mil (5475-5665 mil, or offset by 520 mil per row)
