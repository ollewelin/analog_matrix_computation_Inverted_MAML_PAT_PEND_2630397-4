========================================================================================================================
IMC WORKFLOW - EasyEDA to Python Placement Script
========================================================================================================================

STEP 1: Export from EasyEDA at PCB view
---------
1. File -> File Source... -> Download
2. File stored: Inverted_MAML_IMC.epro2 (in Downloads folder)
3. Unzip the file
4. Extract file: Inverted_MAML_IMC.epru


STEP 2: Run Python placement scripts
---------
python extract_IMC_template.py
(otional) python analyze_IMC.py 
python write_placements_IMC.py 
python verify_placements_IMC.py

Output file generated: autoplaced_output_IMC.epru


STEP 3: Prepare file for EasyEDA import
---------
1. Take file: autoplaced_output_IMC.epru
2. Zip the autoplaced_output_IMC.epru file togheter with 
orignal IMAGE folder and the orgianl project2.json (NOT in any folder)
3. Rename the zip file:
   autoplaced_output_IMC.zip  ->  autoplaced_output_IMC.epro2


STEP 4: Import back into EasyEDA
---------
File -> Import -> EasyEDA(Professional)...
Select: autoplaced_output_IMC.epro2
