========================================================================================================================
IMC WORKFLOW VERSION B - EasyEDA to Python Placement Script
Updated Workflow with X-100mm offset and 2-level hierarchy template
========================================================================================================================

STEP 1: Export from EasyEDA at PCB view
---------
1. File -> File Source... -> Download
2. File stored: Inverted_MAML_IMC.epru (in Downloads folder or working directory)


STEP 2: Extract Template B (New 2-level hierarchy template)
---------
python extract_IMC_template_B.py

This extracts:
- Search area: X: 12.7-25mm, Y: 225-321mm
- Creates: IMC_template_B_x_y_rot.txt
- Creates: IMC_template_B_dict.py (with 2-level hierarchy: designator$CBB17, no /CBBx suffix)


STEP 3: Run Python placement scripts for Version B
---------
python write_placement_IMC_B.py

This applies:
- Template A (3-level hierarchy): all 3x8 blocks with X -100mm offset
  Example: R16$CBB17/CBB1, R16$CBB17/CBB2, ..., R16$CBB18/CBB1, etc.
- Template B (2-level hierarchy): CBB17, CBB18, CBB20 with Y offsets
  Example: U1$CBB17, U1$CBB18 (Y-100mm), U1$CBB20 (Y-200mm)

Output file generated: autoplaced_output_IMC_B.epru


STEP 4: Verify placements (Optional)
---------
python verify_placements_IMC.py

(Use existing verification script)


STEP 5: Prepare file for EasyEDA import
---------
1. Take file: autoplaced_output_IMC_B.epru
2. Zip together with:
   - Original IMAGE folder
   - Original project2.json (NOT in any folder)
3. Rename zip file:
   autoplaced_output_IMC_B.zip  ->  autoplaced_output_IMC_B.epro2


STEP 6: Import back into EasyEDA
---------
File -> Import -> EasyEDA(Professional)...
Select: autoplaced_output_IMC_B.epro2
