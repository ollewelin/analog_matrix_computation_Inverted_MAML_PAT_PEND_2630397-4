SOFTWARE FEATURES IN THIS STANDALONE VERSION
--------------------------------------------------------------------------------
1. Decoupled Snapshot Timing:
   Allows setting any arbitrary ADC sample delay t between 0 and 9.5 ms
   (0 to 9500 us) relative to the 100 Hz autonomous column refresh pulse.
2. Auto-Pause of Background Random In-Data:
   When `maml_probe_single_cell()` is called via UDP (0x17), `g_auto_random_data`
   is automatically cleared to 0, ensuring that unprobed rows remain in a 100%
   quiescent, silent state (all DAC_2 = 128 / 0.0V differential).
3. 36-Cell Simultaneous Column Sampling:
   Each probe read triggers synchronous conversion across all 6 columns of ADC49,
   enabling rapid mapping of the full 6x6 matrix.
4. Autonomous 100 Hz Refresh Preservation:
   Gate voltages on the 100 nF capacitors are refreshed continuously at 100 Hz,
   maintaining stable operating regimes.
